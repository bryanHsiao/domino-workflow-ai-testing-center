# Project Vision: AI Testing Center

## 核心定位

這個專案不是要把 Playwright 整合進 Domino，而是要把「測試能力」變成 Domino Workflow Platform 的核心能力。

如果 Testing Center 做成熟，它不只是為了 HCL 研討會，而會變成公司產品的一個特色功能。研討會只是第一個展示它的舞台。

## 專案背景

公司主要開發平台為 HCL Domino，前端採用 Web Application。

目前系統完成開發後，仍需投入大量人工進行回歸測試。每次功能修改、版本更新或客戶客製，都需要再次確認：

- 表單是否正常
- 流程是否正常
- 權限是否正常
- 簽核是否正常

人工測試成本高、耗時，也容易遺漏。因此，希望建立一套整合於公司產品內的 Testing Center。

## 專案目標

本專案不是單純導入 Playwright。

目標是打造：

```text
Domino Workflow Platform + Playwright + AI
```

形成一個完整的測試平台，讓自動化測試成為產品的一部分，而不是額外工具。

## 產品價值

這不是展示 Playwright，而是展示：

> 我們的平台內建了一套企業級自動化測試能力。

真正的產品價值在於：

- 降低 Domino 專案回歸測試成本
- 減少人工測試遺漏
- 讓測試流程可以被記錄、追蹤與重現
- 將測試結果回寫到 Workflow Platform
- 讓 AI 協助理解錯誤原因與影響範圍
- 讓測試能力成為產品差異化功能

## 長期願景

成熟後的 Testing Center 可以支援：

- 流程級自動化測試
- 表單級自動化測試
- 權限與角色測試
- 簽核流程測試
- 測試歷史追蹤
- Playwright Report 整合
- Screenshot / Trace / Video 保存
- AI 錯誤分析
- AI 測試案例生成
- AI Regression Recommendation
- CI/CD 與 Release Gate 整合
- AI Agent 自動維護測試腳本
